# 安全

Facade Code 在 [github.com/y5ez3g/facadecode](https://github.com/y5ez3g/facadecode) 上公开开发。

## 报告漏洞

**请不要通过公开的 issue 报告安全漏洞。**

请通过仓库的[私密漏洞报告](https://github.com/y5ez3g/facadecode/security/advisories/new)私下报告：打开 Security 标签页，再点 "Report a vulnerability"。请写明：

- 影响到什么，攻击者能借此做什么；
- 怎么复现，越简短越好；
- 你发现问题时的版本号（在 Help > About（帮助 > 关于）里查看）。

你会在那里收到回复。包含该修复的版本发布后，修复和安全公告会一起公开。
