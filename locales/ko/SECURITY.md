# 보안

Facade Code는 [github.com/y5ez3g/facadecode](https://github.com/y5ez3g/facadecode)에서 공개적으로 개발됩니다.

## 취약점 신고

**보안 취약점을 공개 issue로 신고하지 마세요.**

저장소의 [비공개 취약점 신고](https://github.com/y5ez3g/facadecode/security/advisories/new)를 통해 비공개로 신고해 주세요. Security 탭에서 "Report a vulnerability"를 누르면 됩니다. 다음을 적어 주세요.

- 무엇이 영향을 받고, 공격자가 그것으로 무엇을 할 수 있는지
- 재현 방법(가능한 한 짧게)
- 문제를 발견한 버전(Help > About(도움말 > 정보)에서 확인)

답변은 그곳에서 드립니다. 수정이 포함된 릴리스가 나오면 수정 사항과 보안 권고를 함께 공개합니다.
