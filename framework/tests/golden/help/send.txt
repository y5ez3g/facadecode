Send a message to an active agent or guest.

By default, the command ends when Facade Code Framework saves the message in the
recipient's inbox. Use '-w' to wait until Facade Code Framework submits the message
in a managed agent's terminal or a guest reads it. Use '-r' to wait
for a reply. Set the timeout in seconds with '-t'.
Messages can be up to 8,000 characters and 540 lines.

Usage: facade send [OPTIONS] <RECIPIENT> <TEXT>

Examples
  facade send Nova "Check the build"
  facade send -w Nova "Check the build"
  facade send -r -t 120 a5@laptop "Run the tests and reply"

Arguments
  <RECIPIENT>  Active agent or guest reference, agent ID, or unique name
  <TEXT>       Message text

Options
  -w, --wait-delivery      Wait for delivery
  -r, --wait-reply         Wait for a reply and print its text
  -t, --timeout <SECONDS>  Total time to wait, from 1 to 300 seconds (default: 30)
  -h, --help               Show help
