Show Facade Code Framework or agent status.

Without arguments, checks the local Facade Code Framework service without starting it.
Pass an agent to inspect its state, working directory, and launch details.

Usage: facade status [AGENT]

Examples
  facade status
  facade status Nova
  facade status a5@laptop

Arguments
  [AGENT]  Agent reference, agent ID, or unique name (active agents take priority for duplicate names)

Options
  -h, --help  Show help
