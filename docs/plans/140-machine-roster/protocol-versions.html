协商与认证

Daemon
Terminal、IDE、已认证的 MCP actor 与 SSH 机器会话提供 api_versions:[1]。服务端从独立版本集合取最高交集，返回 api_version:1。调用方校验返回值，按已认证身份使用相应目录。
Keeper
Daemon 在本机控制连接提供 api_versions:[1]。Keeper 自己选版，返回 api_version:1 及所持有的活跃进程。双方仍用锁记录、用户、PID 和进程出生标识证明身份。未授权连接关闭。
Relay
外部 hello.params.relay:1 维持原握手。认证后换到 MCP 流。Daemon 以内建身份代表它使用正式 daemon API。

重复版本按同一版本处理。缺失、空数组、错误类型及非正数触发 invalid_argument。合法但无交集时，supported_api_versions 列出被访问端点的集合。
