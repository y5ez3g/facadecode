# Seguridad

Facade Code se desarrolla en abierto en [github.com/y5ez3g/facadecode](https://github.com/y5ez3g/facadecode).

## Cómo reportar una vulnerabilidad

**No reportes vulnerabilidades de seguridad mediante issues públicas.**

Repórtalas de forma privada mediante el [reporte privado de vulnerabilidades](https://github.com/y5ez3g/facadecode/security/advisories/new) del repositorio: la pestaña Security y luego "Report a vulnerability". Indica:

- qué se ve afectado y qué podría hacer un atacante con ello;
- cómo reproducirlo, de la forma más breve posible;
- la versión en la que lo viste, que aparece en Help > About (Ayuda > Acerca de).

Recibirás respuesta allí, y la corrección y el aviso de seguridad se publican juntos en cuanto una versión incluya la corrección.
