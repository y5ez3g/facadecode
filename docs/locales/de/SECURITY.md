# Sicherheit

Facade Code wird offen auf [github.com/y5ez3g/facadecode](https://github.com/y5ez3g/facadecode) entwickelt.

## Eine Sicherheitslücke melden

**Bitte melde Sicherheitslücken nicht über öffentliche Issues.**

Melde sie vertraulich über die [private Meldung von Sicherheitslücken](https://github.com/y5ez3g/facadecode/security/advisories/new) des Repositorys: im Tab Security, dann „Report a vulnerability“. Gib bitte an:

- was betroffen ist und was ein Angreifer damit anstellen könnte;
- wie es sich reproduzieren lässt, so knapp wie möglich;
- die Version, in der du es bemerkt hast, aus Help > About (Hilfe > Info).

Du bekommst dort eine Antwort, und Fix und Advisory werden gemeinsam veröffentlicht, sobald ein Release den Fix enthält.
