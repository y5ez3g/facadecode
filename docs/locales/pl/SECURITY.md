# Bezpieczeństwo

Facade Code jest rozwijane otwarcie na [github.com/y5ez3g/facadecode](https://github.com/y5ez3g/facadecode).

## Zgłaszanie luki

**Prosimy nie zgłaszać luk bezpieczeństwa w publicznych issues.**

Zgłaszaj je prywatnie przez [prywatne zgłaszanie podatności](https://github.com/y5ez3g/facadecode/security/advisories/new) w repozytorium: zakładka Security, a potem „Report a vulnerability”. Napisz:

- czego dotyczy luka i co atakujący mógłby dzięki niej zrobić;
- jak ją odtworzyć, możliwie najkrócej;
- wersję, w której ją zauważyłeś, z Help > About (Pomoc > Informacje).

Odpowiedź dostaniesz tam, a poprawka i biuletyn bezpieczeństwa są publikowane razem, gdy poprawka trafi do wydania.
