# Безопасность

Facade Code разрабатывается открыто на [github.com/y5ez3g/facadecode](https://github.com/y5ez3g/facadecode).

## Как сообщить об уязвимости

**Пожалуйста, не сообщайте об уязвимостях безопасности через публичные issue.**

Сообщайте о них конфиденциально через [приватные отчёты об уязвимостях](https://github.com/y5ez3g/facadecode/security/advisories/new) в репозитории: вкладка Security, затем «Report a vulnerability». Укажите:

- что затронуто и что злоумышленник может с этим сделать;
- как воспроизвести проблему, как можно короче;
- версию, в которой вы её заметили, из Help > About (Справка > О программе).

Ответ придёт там же, а исправление и бюллетень безопасности публикуются одновременно, как только исправление войдёт в релиз.
