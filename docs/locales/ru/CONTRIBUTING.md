# Как внести вклад в Facade Code

Спасибо за помощь. Facade Code разрабатывается открыто на [github.com/y5ez3g/facadecode](https://github.com/y5ez3g/facadecode).

## Ошибки и идеи

Создайте [issue](https://github.com/y5ez3g/facadecode/issues); пункт Help > Report Issue (Справка > Сообщить о проблеме) открывает новый issue, в котором уже указана ваша версия. Сначала поищите среди существующих issue, а если это ошибка, опишите:

- что вы сделали, что ожидали и что произошло на самом деле;
- версию из Help > About (Справка > О программе) и вашу операционную систему;
- если проблема с агентом, то какой CLI агента и какой версии.

Об уязвимостях безопасности не сообщают в issue; см. [`SECURITY.md`](SECURITY.md).

## Код

Как устроена работа с этим репозиторием, описано в [`docs/ide/ENGINEERING.md`](../../ide/ENGINEERING.md): как настроить сборку, какие команды проверяют изменение, и полный текст правил ниже.

- Создавайте ветку от `main` с именем `feature/<number>-<name>`.
- Только merge, никакого rebase: фича попадает в `main` через `--no-ff` после ревью.
- Держите файлы Facade Code вместе, а в файлы VS Code добавляйте необязательные хуки, не переписывая их логику, чтобы новые версии VS Code было проще вливать в форк.
- У каждой фичи есть переключатель, и в выключенном состоянии это обычный VS Code.
- Каждое изменение должно сопровождаться тестами.
- Документацию, комментарии и сообщения коммитов пишите на английском.

Что должна делать каждая фича, описано в [`docs/ide/`](../../ide/). Чтобы изменить поведение, начните со спецификации или сначала откройте issue для обсуждения.
