# Sécurité

Facade Code est développé ouvertement sur [github.com/y5ez3g/facadecode](https://github.com/y5ez3g/facadecode).

## Signaler une faille

**Merci de ne pas signaler les failles de sécurité dans des issues publiques.**

Signalez-les en privé grâce au [signalement privé de vulnérabilités](https://github.com/y5ez3g/facadecode/security/advisories/new) du dépôt : l'onglet Security, puis « Report a vulnerability ». Merci d'indiquer :

- ce qui est touché, et ce qu'un attaquant pourrait en faire ;
- comment reproduire le problème, le plus brièvement possible ;
- la version dans laquelle vous l'avez constaté, visible dans Help > About (Aide > À propos).

Vous recevrez une réponse à cet endroit, et le correctif et l'avis de sécurité sont publiés ensemble dès qu'une version contient le correctif.
