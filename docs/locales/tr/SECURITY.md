# Güvenlik

Facade Code, [github.com/y5ez3g/facadecode](https://github.com/y5ez3g/facadecode) üzerinde açık olarak geliştirilir.

## Güvenlik açığı bildirme

**Lütfen güvenlik açıklarını herkese açık issue'lar üzerinden bildirmeyin.**

Bunları deponun [özel güvenlik açığı bildirimi](https://github.com/y5ez3g/facadecode/security/advisories/new) özelliğiyle gizli olarak bildirin: Security sekmesini, ardından "Report a vulnerability" seçeneğini açın. Lütfen şunları belirtin:

- neyin etkilendiğini ve bir saldırganın bununla ne yapabileceğini;
- sorunun nasıl yeniden üretileceğini, olabildiğince kısa;
- sorunu gördüğünüz sürümü, Help > About (Yardım > Hakkında) bölümünden.

Yanıtı orada alırsınız; düzeltme ve güvenlik bülteni, düzeltmeyi içeren bir sürüm çıktığında birlikte yayımlanır.
