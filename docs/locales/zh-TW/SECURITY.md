# 安全性

Facade Code 在 [github.com/y5ez3g/facadecode](https://github.com/y5ez3g/facadecode) 上公開開發。

## 回報漏洞

**請不要透過公開的 issue 回報安全性漏洞。**

請透過儲存庫的[私人漏洞回報](https://github.com/y5ez3g/facadecode/security/advisories/new)私下回報：開啟 Security 分頁，再點選「Report a vulnerability」。請寫明：

- 影響的範圍，以及攻擊者能利用它做什麼；
- 如何重現，越精簡越好；
- 你發現問題時的版本（在 Help > About（說明 > 關於）裡查看）。

你會在那裡收到回覆。包含該修正的版本發布後，修正內容與安全性公告會一併公開。
