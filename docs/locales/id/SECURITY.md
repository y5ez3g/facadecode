# Keamanan

Facade Code dikembangkan secara terbuka di [github.com/y5ez3g/facadecode](https://github.com/y5ez3g/facadecode).

## Melaporkan kerentanan

**Mohon jangan melaporkan kerentanan keamanan melalui issue publik.**

Laporkan secara privat melalui [pelaporan kerentanan privat](https://github.com/y5ez3g/facadecode/security/advisories/new) di repositori: buka tab Security, lalu "Report a vulnerability". Mohon sebutkan:

- apa yang terdampak, dan apa yang bisa dilakukan penyerang dengannya;
- cara mereproduksinya, sesingkat mungkin;
- versi yang Anda pakai saat menemukannya, dari Help > About (Bantuan > Tentang).

Anda akan mendapat jawaban di sana, dan perbaikan beserta advisory-nya dipublikasikan bersamaan begitu ada rilis yang membawa perbaikan tersebut.
