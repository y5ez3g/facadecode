# セキュリティ

Facade Code は [github.com/y5ez3g/facadecode](https://github.com/y5ez3g/facadecode) でオープンに開発しています。

## 脆弱性の報告

**セキュリティの脆弱性を公開の issue で報告しないでください。**

リポジトリの[非公開の脆弱性報告](https://github.com/y5ez3g/facadecode/security/advisories/new)から、非公開で報告してください。Security タブを開き、「Report a vulnerability」を選びます。次のことを書いてください。

- 何が影響を受け、攻撃者がそれで何をできるか
- 再現手順（できるだけ短く）
- 問題を確認したバージョン（Help > About（ヘルプ > バージョン情報）で確認できます）

回答はそこで行います。修正を含むリリースが出た時点で、修正とセキュリティ アドバイザリを同時に公開します。
