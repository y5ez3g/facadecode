# Facade Code へのコントリビュート

ご協力ありがとうございます。Facade Code は [github.com/y5ez3g/facadecode](https://github.com/y5ez3g/facadecode) でオープンに開発しています。

## バグやアイデア

[issue](https://github.com/y5ez3g/facadecode/issues) を作成してください。Help > Report Issue（ヘルプ > 問題の報告）を使うと、バージョンが記入された状態で新しい issue が開きます。まず既存の issue を検索し、バグの場合は次のことを書いてください。

- 何をしたか、何を期待したか、実際に何が起きたか
- バージョン（Help > About（ヘルプ > バージョン情報）で確認できます）と OS
- エージェントの問題なら、どのエージェント CLI のどのバージョンか

セキュリティの脆弱性は issue では報告しないでください。[`SECURITY.md`](SECURITY.md) を参照してください。

## コード

このリポジトリでの作業の進め方は [`docs/ide/ENGINEERING.md`](../../ide/ENGINEERING.md) にまとめています。ビルド環境の準備、変更を確認するコマンド、そして以下のルールの全文です。

- `main` から `feature/<name>` という名前でブランチを切ります。
- rebase はせず、必ず merge します。機能はレビューを経て、`--no-ff` で `main` に入ります。
- Facade Code のファイルは一か所にまとめ、VS Code のファイルにはロジックを書き換えるのではなく、オプションのフックを追加します。新しい VS Code を取り込むコストを低く保つためです。
- どの機能にもスイッチがあり、オフにすれば素の VS Code です。
- 変更には必ずテストを添えます。
- ドキュメント、コメント、コミット メッセージはすべて英語で書きます。

各機能が何をすべきかは [`docs/ide/`](../../ide/) にあります。動作を変える場合は仕様から始めるか、先に issue を立てて相談してください。
