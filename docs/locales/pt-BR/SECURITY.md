# Segurança

O Facade Code é desenvolvido abertamente em [github.com/y5ez3g/facadecode](https://github.com/y5ez3g/facadecode).

## Como reportar uma vulnerabilidade

**Não reporte vulnerabilidades de segurança em issues públicas.**

Reporte-as de forma privada, pelo [relato privado de vulnerabilidades](https://github.com/y5ez3g/facadecode/security/advisories/new) do repositório: a aba Security e, depois, "Report a vulnerability". Informe:

- o que é afetado e o que um atacante poderia fazer com isso;
- como reproduzir, da forma mais curta possível;
- a versão em que você viu o problema, que aparece em Help > About (Ajuda > Sobre).

A resposta vem por lá, e a correção e o aviso de segurança são publicados juntos quando uma versão trouxer a correção.
