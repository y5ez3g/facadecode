Rename a machine

Usage: facade machine rename <MACHINE> <NAME>

Give a machine a new name, from any machine with a route to it. Addresses with the old name, such as
'a17@gpu', stop working.

Arguments:
  <MACHINE>  Machine ID or name
  <NAME>     New name

Options:
  -h, --help  Print help

Examples:
  # Rename machine gpu to lab
  facade machine rename gpu lab
