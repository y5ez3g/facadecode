Facade runs AI coding agents, such as Claude Code and Codex, and lets you work with them as a team.
Facade keeps the terminals of the agents it starts, so you can watch them, step in or give them a
task. Agents can also start and message one another to share the work.

Learn more at https://facadecode.com

Usage: facade [OPTIONS] [COMMAND]

Agents:
  start        Start an agent
  list         List agents
  attach       Watch an agent and use its terminal
  stop         Stop one or more agents
  resume       Resume an ended agent's session
  remove       Remove one or more agents
  rename       Rename an agent

Inspect and control:
  inspect      Show what an agent is doing
  screen       Print an agent's recent output
  type         Type text or press keys in an agent's terminal

Messages:
  send         Send a message to an agent or the human
  messages     Read the inbox of the agent in this terminal

Setup and info:
  machine      Connect to Facade on other machines
  integration  Let CLIs you start yourself join Facade
  status       Show Facade's status
  version      Print the version
  completion   Print a shell completion script

Options:
  -h, --help     Print help
  -V, --version  Print the version

Run 'facade <COMMAND> --help' for more information on a command.
