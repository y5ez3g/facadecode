Start AI coding agents and use their terminals from the Shell. You can watch an agent work, step in
or send it a task. Agents can also start and message one another.

Learn more at https://facadecode.com

Usage: facade [OPTIONS] [COMMAND]

Agents:
  start       Start an agent
  list        List active agents
  attach      Watch an agent and use its terminal
  stop        Stop one or more agents
  resume      List resumable sessions or resume one
  remove      Remove one or more agents
  rename      Rename an agent

Inspect and control:
  inspect     Show what an agent is doing
  screen      Print an agent's recent output
  type        Type text or press keys in an agent's terminal

Messages:
  send        Send a message to an agent

Setup and info:
  machine     Connect to other machines over SSH
  status      Show Orchestrator status
  version     Print the version
  completion  Print a shell completion script
  upgrade     Upgrade Facade Code

Options:
  -h, --help     Print help
  -V, --version  Print the version

Run 'facade <COMMAND> --help' for more information on a command.
