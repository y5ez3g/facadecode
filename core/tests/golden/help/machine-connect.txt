Connect to a machine while this command runs

Usage: facade machine connect [OPTIONS] <SSH-ARG>...

Keep a temporary SSH connection until you press Ctrl-C or close this terminal. Use the same SSH
arguments and optional '--home' as 'facade machine add'.

Arguments:
  <SSH-ARG>...  The arguments you would use after ssh, including the destination

Options:
      --home <PATH>  Remote Facade home. Put this option before the SSH arguments
  -h, --help         Print help

Examples:
  # Connect to gpu for now
  facade machine connect gpu
