Show Orchestrator status

Usage: facade status [OPTIONS]

Show the Orchestrator's version, Facade home, and settings file. When running, it also shows the
daemon and keeper process IDs, active agent count and connected machines. Local status checks for a
running service. '--machine' queries another machine and wakes it if needed.

Options:
      --json               Print the status as JSON
      --machine <MACHINE>  Machine name or ID from 'facade machine list'
  -h, --help               Print help

Examples:
  # Check the local Orchestrator
  facade status

  # Check the Orchestrator on gpu
  facade status --machine gpu
