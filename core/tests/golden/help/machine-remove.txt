Remove a saved connection

Usage: facade machine remove <MACHINE>

Remove a saved connection to a machine. Its agents keep running, and other machines may still have a
route to it.

Arguments:
  <MACHINE>  Machine name or 'id:' followed by 8 to 32 hex digits from 'facade machine list'

Options:
  -h, --help  Print help

Examples:
  # Stop connecting to gpu
  facade machine remove gpu
