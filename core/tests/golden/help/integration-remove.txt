Remove Facade from a CLI's settings

Usage: facade integration remove [OPTIONS] <CLI>

Remove the settings that let new sessions of this CLI join Facade. Facade keeps any changes you made
and shows any settings that need attention.

Arguments:
  <CLI>  claude, codex, opencode, pi, muse or agy

Options:
      --json  Print the result as JSON
  -h, --help  Print help

Examples:
  # Remove Facade from Claude Code's settings
  facade integration remove claude
