Connect to other machines over SSH

Usage: facade machine <COMMAND>

Work with agents on other machines. Orchestrators connect over SSH and open no port. Once two
machines are connected, you can list, start and message agents on both from either one.

Commands:
  add      Connect to a machine and save its SSH arguments
  connect  Connect to a machine while this command runs
  list     List machines
  remove   Remove a saved connection
  rename   Rename a machine

Options:
  -h, --help  Print help

Examples:
  # Connect to gpu from your SSH config
  facade machine add gpu

  # See the machines this one connects to
  facade machine list
