Send a message to an agent

Usage: facade send <RECIPIENT> <TEXT>

Send a message from the command line. The Orchestrator waits up to 30 seconds for a managed agent's
terminal to receive it or a guest to read it. On delivery, this command prints the message address.

Arguments:
  <RECIPIENT>  Agent address, ID or name
  <TEXT>       Message text, up to 8,000 characters and 540 lines

Options:
  -h, --help  Print help

Examples:
  # Ask an agent on gpu to review a change
  facade send a3@gpu "Please review the diff in src/parser.rs"
