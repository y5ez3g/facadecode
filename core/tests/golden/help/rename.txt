Rename an agent

Usage: facade rename <AGENT> <NAME>

Change the agent's display name. Pass an empty or blank name to let the Orchestrator choose one.

Arguments:
  <AGENT>  Agent address such as a17@gpu, or an agent ID or name
  <NAME>   New name, or " " for one chosen by the Orchestrator

Options:
  -h, --help  Print help

Examples:
  # Rename agent a3 to reviewer
  facade rename a3 reviewer

  # Let the Orchestrator choose a new name for agent a3
  facade rename a3 " "
