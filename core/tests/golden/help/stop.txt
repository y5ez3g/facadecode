Stop one or more agents

Usage: facade stop <AGENT>...

Stop agents that Facade started and keep them in your list. You can still read their screens, remove
them or resume a saved session if the CLI supports it.

Arguments:
  <AGENT>...  Agent ID or name

Options:
  -h, --help  Print help

Examples:
  # Stop agent a3
  facade stop a3

  # Stop two agents, by ID and by name
  facade stop a3 Ada
