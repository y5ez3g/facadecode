Stop one or more agents

Usage: facade stop <AGENT>...

Stop running managed agents. You can read their screens, remove them or resume a saved session.
Agents they started keep running.

Arguments:
  <AGENT>...  Agent addresses, IDs or names

Options:
  -h, --help  Print help

Examples:
  # Stop agent a3
  facade stop a3

  # Stop two agents, by ID and by name
  facade stop a3 Ada
