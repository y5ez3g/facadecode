Watch an agent and use its terminal

Usage: facade attach <AGENT>

Watch a running managed agent and use its terminal. Ctrl-] detaches and returns 0. If the agent
exits first, this command returns the CLI's exit code. Use 'facade screen' to read an ended agent's
last screen.

Arguments:
  <AGENT>  Agent address such as a17@gpu, or an agent ID or name

Options:
  -h, --help  Print help

Examples:
  # Watch agent a3
  facade attach a3

  # Watch the agent named Pixel
  facade attach Pixel
