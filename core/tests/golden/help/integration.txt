Let CLIs you start yourself join Facade

Usage: facade integration <COMMAND>

Use Facade's tools and messages in CLIs you start yourself, outside Facade. Once you add an
integration, new sessions of that CLI appear in 'facade list' as guests and keep their own
terminals.

Commands:
  add     Add Facade to a CLI's settings
  remove  Remove Facade from a CLI's settings
  list    List CLI integrations

Options:
  -h, --help  Print help

Examples:
  # Let Claude Code sessions you start yourself join Facade
  facade integration add claude
