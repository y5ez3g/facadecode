Connect to a machine and save its SSH arguments

Usage: facade machine add [OPTIONS] <SSH-ARG>...

Connect over SSH and save the connection. Use the same arguments you would give ssh. Put '--home'
before those arguments to use another remote Facade home. SSH can ask for a password or host key
here. Saved machines connect automatically while awake. An operation that names a sleeping machine
wakes it. Run the same command again when a saved connection needs a login.

Arguments:
  <SSH-ARG>...  The arguments you would use after ssh, including the destination

Options:
      --home <PATH>  Remote Facade home. Put this option before the SSH arguments
  -h, --help         Print help

Examples:
  # Connect to gpu from your SSH config
  facade machine add gpu

  # Connect as another user on port 2222
  facade machine add -p 2222 me@10.0.0.5

  # Use an SSH key and another remote Facade home
  facade machine add --home /srv/facade -i ~/.ssh/work me@gpu
