Show what an agent is doing

Usage: facade inspect [OPTIONS] <AGENT>

See the agent's address, state, launch settings and saved session. You can also check who started
it, who is watching its terminal, and whether YOLO is on.

Arguments:
  <AGENT>  Agent address such as a17@gpu, or an agent ID or name

Options:
      --json  Print the details as JSON
  -h, --help  Print help

Examples:
  # Show what agent a3 is doing
  facade inspect a3

  # Print agent a3's details as JSON
  facade inspect --json a3
