Show what an agent is doing

Usage: facade inspect [OPTIONS] <AGENT>

See what an agent is doing and what it is waiting for. You can also check its Facade tools, its
saved session and the last text submitted to it.

Arguments:
  <AGENT>  Agent ID or name; add @MACHINE for another machine's agent, such as a17@gpu

Options:
      --json  Print the details as JSON
  -h, --help  Print help

Examples:
  # Show what agent a3 is doing
  facade inspect a3

  # Print agent a3's details as JSON
  facade inspect --json a3
