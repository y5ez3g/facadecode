Remove one or more agents

Usage: facade remove <AGENT>...
Alias: facade rm

Remove agents that the Orchestrator started, along with their screens and inboxes. The Orchestrator
stops any that are still running, and each CLI keeps its saved session.

Arguments:
  <AGENT>...  Agent addresses, IDs or names

Options:
  -h, --help  Print help

Examples:
  # Remove agent a3
  facade rm a3

  # Remove two agents
  facade rm a3 a4
