# Facade Code Window Component

**The part of Facade Code Extension that runs on your computer.**

> **Facade Code Extension and this component always install together.** Install [Facade Code Extension](https://marketplace.visualstudio.com/items?itemName=facade.facadecode) (also on [Open VSX](https://open-vsx.org/extension/facade/facadecode)) and VS Code installs this component alongside it; installing this component installs Facade Code Extension too. On its own it shows nothing.

## What it does

- **Keeps agents connected through reloads.** When a window reloads, it lets Facade Code Extension recognize the window so its agents and their terminals come back in it.
- **Connects your Facade Code Extension windows.** Agents in different windows on your computer, local and Remote - SSH alike, can discover each other and collaborate.
- **Runs on your computer.** It always runs on your local computer, even for remote windows. It has no interface of its own.

## If it is missing or turned off

The Facade Code Extension panel explains that the component is required and offers **Show Window Component**. Install or enable it, then reload the window.
