# Facade Code Window Component

This is part of [Facade Code](https://marketplace.visualstudio.com/items?itemName=facade.facadecode), also on [Open VSX](https://open-vsx.org/extension/facade/facadecode). Install **Facade Code** instead: VS Code installs this component with it as a dependency.

The Window Component always runs on your computer, also for remote windows. It lets Facade Code recognize each window and its agents' terminals after a reload. It has no interface of its own.
